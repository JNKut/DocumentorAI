# Shop Twist and Thread - Pricing Calculator Guide

## How to Use the AI Assistant for Pricing

### Simple Pricing Questions
- "How much is a hoodie?"
- "What's the cost of a tank top with my name?"
- "Price for a t-shirt with 'TEAM' on it?"

### Complex Pricing Questions  
- "How much for a premium hoodie with 'CHAMPIONS' and a team patch?"
- "What would a tank top cost with 8 letters, 2 extra patches, and a pennant flag?"
- "Price for 5 hoodies with names and team logos?"

### Package Deal Questions
- "What's included in the starter package?"
- "How much would the deluxe package cost for a sweatshirt?"
- "What's the best deal for a custom hoodie?"

### Bulk Order Questions
- "What discount do I get for 10 hoodies?"
- "How much for 25 team shirts with names?"
- "Bulk pricing for youth sports team?"

## Pricing Formula the AI Uses

**Base Price + Customization Costs + Special Features + Package Discounts = Total**

### Base Pricing Structure
- Standard items include: garment + up to 3 letters + 1 patch
- Premium items: +$15-20 depending on garment type
- Additional letters: +$2 for every letter beyond 3rd
- Extra patches: +$5 each
- Special features: $4-25 depending on complexity

### Package Deals Save Money
- Starter: Base + $12 (great for simple custom pieces)
- Deluxe: Base + $28 (best value for most customers)  
- Premium: Base + $45 (everything included)

### Bulk Discounts Apply Automatically
- 3+ items: 5% off
- 6+ items: 10% off
- 11+ items: 15% off
- 21+ items: 20% off

## Tips for Customers
1. **Ask for package deals** - Often better value than individual add-ons
2. **Consider bulk orders** - Significant savings start at just 3 items
3. **Be specific** - Include all details (letters, patches, special features) for accurate quotes
4. **Ask about rush orders** - Available but adds 25-75% to total cost

## Tips for Business Owner
1. **Update knowledge base** - Modify pricing in the knowledge base file as needed
2. **Seasonal adjustments** - Add holiday specials or sale information
3. **New products** - Add new garment types with their base pricing
4. **Monitor AI responses** - Check that calculations remain accurate
